# Hotel Booking Cancellation Prediction

## Project Overview

This repository contains the work developed for the Capstone Project of the Higher Diploma in Data Analytics for Business at CCT College Dublin.

The project focuses on predicting hotel booking cancellations using machine learning and historical hotel reservation data.

## Project Aim

The aim of the project is to develop a machine learning-based solution capable of predicting whether a hotel reservation is likely to be cancelled using information available at the time of booking.

## Project Objectives

- Analyse and prepare historical hotel booking data.
- Identify patterns associated with hotel booking cancellations.
- Develop and compare machine learning classification models.
- Evaluate model performance using appropriate classification metrics.
- Present the findings through a business-oriented dashboard.

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook / Google Colab

## Project Status

The project is currently under development as part of the CCT College Dublin Capstone Project.
